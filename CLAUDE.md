# CLAUDE.md

The logo universe of MUNify, CHASE and DELEGATOR as an npm package
(`@deutschemodelunitednations/munify-brand`). See README.md for what it exports and
GUIDELINES.md for how the marks may be used.

- **`masters/` are the only drawings**, one blue (`#01548F`) SVG per product and variant.
  Everything in `assets/` and `src/lib/marks.generated.ts` is generated by `bun run generate`
  (`scripts/generate.ts`) and never edited by hand. Change a master, the generator, the product
  table, the splash list or the URL layout (`src/lib/{products,splash,web}.ts`) → regenerate and
  commit the output; `assets.test.ts` fails otherwise (reformatting an input counts).
- **Never alter the marks themselves** (gaps, opening, rotation, proportions): the reasons are in
  GUIDELINES.md §8, the geometry in `workspace/` (Python).
- **Colour rules** (GUIDELINES §4): DMUN-Blau never on navy, turquoise never in a mark, no effects
  outside the `lift-*` set.
- The package is generic over the apps: no Paraglide, no `$app/*`, no app routes. App-specific
  manifest fields come in through the plugin's `manifest` option.
- **Two or more parameters take one object**, functions only, no `as` casts (narrowest
  `// TYPE-SAFETY-EXCEPTION:` where unavoidable), as in the apps.
- Every change ships with tests (`*.test.ts` next to the code). Run `bun run check`,
  `bun run test` and `bun run format` before committing.
- Breaking changes bump the minor version while below 1.0 and need matching PRs in the apps
  (munify-delegator, munify-chase, munify-docs) and a refreshed `cdn-container/cdn/munify/`.
- Commits follow Conventional Commits, as in the apps. Licences: code MIT, marks CC BY-ND 4.0.
